# Antigravity Physics Sandbox

An interactive 2D canvas physics simulation demonstrating buoyant, negative-gravity forces, localized inverse-square repulsion, and fluid damping.

🔗 **[Live Demo](https://jilinsebastian123.github.io/antigravity-sandbox/)**

## Features
- **Negative Gravity Core:** Upward buoyancy vectors simulating zero/inverted gravity.
- **Interactive Cursor Physics:** Switch between localized repulsion and gravitational attraction.
- **Dynamic Particle Spawning:** Click anywhere to spawn high-velocity particle clusters.
- **Real-Time Tuning:** Sliders to adjust gravity direction and fluid air resistance.

## Tech Stack
- Vanilla HTML5 Canvas
- CSS3
- JavaScript (ES6)
